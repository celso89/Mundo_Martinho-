Os 3 passos no GitHub
  1. Envie a foto descarregada para a pasta portfolio: Add file → Upload files → Commit.
  2. Abra portfolio.json, toque no lápis ✏️, apague tudo, cole o código copiado e faça Commit changes.
  3. Espere 1–3 minutos (o Render atualiza sozinho) e recarregue o site.
